# Seven Seas admin design system

Use the existing Manrope admin language: off-white workspace, white rectangular panels, 1px neutral borders, charcoal typography, and restrained gold accents. Controls are compact and direct. Do not introduce gradients, rounded SaaS cards, decorative illustration, or new navigation.

For the gallery editor, prioritize a single obvious flow: album title, album description, and one multi-image media-library action. Selected images should appear as a reorderable thumbnail grid with count, remove controls, and optional per-image captions kept visually secondary. Preserve the existing admin shell and sticky publish bar.
